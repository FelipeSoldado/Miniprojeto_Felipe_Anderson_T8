## Sobre o Projeto
Este repositório contém o miniprojeto de Análise Exploratória de Dados desenvolvido como parte da formação acadêmica. O objetivo principal foi realizar o carregamento, limpeza, tratamento (ETL) e análise de uma base de dados do setor de varejo, extraindo insights valiosos para a tomada de decisão no negócio.

## Estrutura do Repositório
* `Miniprojeto_Felipe_Anderson_Dos_Santos_T8.ipynb`: Notebook principal contendo todo o código documentado, etapas de tratamento dos dados, gráficos e conclusões analíticas.
* *Nota sobre os dados:* A base de dados tratada (`.csv`) excede o limite de tamanho para upload direto no GitHub, mas todo o processo de tratamento e validação encontra-se integralmente reproduzido e documentado no notebook.

## Principais Conclusões e Recomendações de Negócio
* **Concentração de Vendas:** As categorias de Alimentos e Bebidas concentram a grande maioria das transações, exigindo atenção redobrada na gestão de estoque para evitar rupturas.
* **Otimização Operacional:** Identificou-se padrões sazonais e comportamentais importantes que auxiliam no direcionamento de campanhas de marketing e logística comercial.
